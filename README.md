# Анализ датасета краудфандинговой платформы Kickstarter
**Учебный проект по анализу данных | Инструменты: SQL (SQLite), Python (Pandas), Power BI**

## О проекте

Этот проект был выполнен в рамках портфолио для отработки **полного цикла работы с данными**: от очистки и трансформации до визуализации и формулировки выводов. Основной фокус — не решение конкретной бизнес-задачи, а **освоение различных инструментов и методик** работы с реальными данными.

**Цель проекта:**  
Проанализировать 320 тыс. проектов с платформы Kickstarter за 2009-2016 гг. оценить общее положение и динамику рынка на взятом интервале времени, а также выявить факторы, влияющие на успех кампании.

**Датасет:**  
Источник: Kaggle / "Kickstarter Projects" от пользователя kemical (Mickaël Mouillé) <br>
https://www.kaggle.com/datasets/kemical/kickstarter-projects <br>
Объём: 320+ тыс. записей, 13 колонок <br>
Период: 2009–2017 гг. <br>

## Структура проекта

Источник(CSV)/ - исходный датасет .csv <br>
SQL/ - база данных .db + папка с запросами .sql <br>
Python/ - Jupiter-ноутбук с комментариями .ipynb + папка с экспортом данных .csv <br>
BI/ - файлы дашборда .pbix + .pdf <br>

## Что было сделано

### 1. SQL (SQLite) — 10 аналитических задач
- Создан очищенный VIEW
- Анализ успешности по категориям, странам, времени
- Квартильный анализ целей
- Корреляционный анализ
- Кластеризация проектов по длительности кампании

### 2. Python (Pandas) — исследовательский анализ
- Загрузка данных из SQLite, преобразование типов, удаление выбросов по 99-му перцентилю
- Feature engineering: создание бинарного флага успеха, расчёт длительности кампании
- Анализ успешности по категориям и странам, оценка "качества" спонсоров
- Анализ длительности кампаний: поиск оптимального диапазона и популярных значений
- Корреляционный анализ: выявление сильнейших предикторов успеха (backers, goal)
- Текстовый анализ названий (категория Technology): парсинг, фильтрация стоп-слов, рейтинг ключевых слов по успешности
- Экспорт очищенных данных в CSV для Power BI

### 3. Power BI — интерактивный дашборд
- 4 страницы с данными (Ключевые показатели, Общая статистика, География, Факторы успеха)
- Интерактивность: фильтры по категориям, времени, странам
- Heatmap сезонности, scatter plot "цель vs сбор", интерактивная карта с отображением сборов, treemap проектов по категориям и прочие визуализации.
